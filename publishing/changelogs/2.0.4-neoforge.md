# LightSpeedRe 2.0.4 (NeoForge 1.21.1)

- Preserve configured resource caches, parallel pack lookup, and the dedicated reload executor when Connector or Continuity is installed.
- Preserve renderer and model layer failures instead of substituting empty renderers or skipping layer definitions.
- Resource reload failure isolation requires explicit listener class prefixes and is disabled by default.

## 中文

- 共装 Connector 或 Continuity 时，保留配置中的资源缓存、资源包并行查找和专用重载执行器。
- 保留渲染器和模型层提供方抛出的错误，不再替换为空渲染器或跳过模型层定义。
- 资源重载失败隔离默认关闭，启用时需要指定监听器类名前缀。
