# LightSpeedRe 2.0.2hotfix

- Keep ModernFix's audit and cleanup on the render thread when class initialization can require an OpenGL context.
- Preserve Lightspeed's configured cache and concurrency flags when LightLoad is installed.
- Move LightLoad class-archive compression and publication off the render thread. The original archive is still written, and shutdown waits for completion.
- Preserve resource-output callback exceptions without repeating the callback through a fallback scan.
- Use bounded neutral resource caches and atomic file publication. Old Java object caches are ignored and rebuilt; current lookup results take precedence over asynchronous disk loads.
- Correct the known JDTE spawner accessor descriptor while retaining its original Mixin callbacks.
- Keep the LightLoad reflection ABI without enabling the duplicate initial-pack-preload path.
- Remove saved Lightspeed bootstrap arguments from the current launcher profile while preserving user arguments and worker settings. Normal startup uses native mod loading without automatically installing or attaching a JVM agent.
- Retain the completed mod-loading and initial-resource-reload requirement for title-ready logging.

Existing startup optimizations remain enabled. No fixed startup time or universal percentage improvement is claimed.
