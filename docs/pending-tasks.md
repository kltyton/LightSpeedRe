已通过 mclo.gs 官方原始日志接口读取：[慢启动日志](https://mclo.gs/tuTANed)、[短启动日志](https://mclo.gs/32k1pm7)、[模组列表](https://mclo.gs/qs8zFy3)。两份启动日志的模组 JAR 文件名差异只有 `lightspeed-1.21.1-1.2.3.jar`，Slag 和 Create Compat 均出现在两份日志中。慢日志从 08:00:21 到标题记录 08:11:40，短日志从 07:53:50 到 07:58:08；慢日志资源重载期有约 340 秒无日志区间，短日志对应最大区间约 76 秒。由此可以确认当时的回退与 Lightspeed 共装有关，但缺少该次运行的线程栈，不能把某一个方法断言为唯一根因。
